# ✊ オルグ！ ～組合員ゼロから始める職場制圧記～

労働組合をテーマにした**放置・クリッカーゲーム**です。
声をかけて 🔥闘志 を集め、仲間を増やし、ひとり組合から万国の労働者まで駆け上がります。

ビルド不要・依存ゼロの静的サイトなので、**GitHub Pages にそのまま置くだけ**で動きます。

## あそびかた

1. **「声をかける」** を押して 🔥闘志 を稼ぐ
2. 闘志で **組合員を加入させる**（新入組合員 → 職場委員 → … → 伝説の委員長）。組合員は自動で闘志を生む
3. **強化アイテム**で生産量とクリック効率を伸ばす（組合員が増えるほど解放される）
4. たまに画面に現れる **📰号外** をクリックすると強力なバフ（まれに妨害イベントも）
5. 行き詰まったら **🔁組織再編**。すべてリセットする代わりに永続ボーナス「組合歴」を獲得

セーブはブラウザの `localStorage` に自動保存されます（20秒ごと／離脱時）。
オフライン中も **効率50％・最大8時間** ぶん進行します。データは端末の外に出ません。

## 中身

| 要素 | 数 |
|---|---|
| 組合員（生産者） | 12種 |
| 強化アイテム | 92個（組合員強化72／クリック12／全体8） |
| 実績 | 24種（1つにつき全生産 +1%） |
| 号外バフ | 7種 |
| 組織ランク | 11段階 |

## ローカルで動かす

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

`file://` で直接開いても動きますが、ローカルサーバー経由を推奨します。

## GitHub Pages で公開する

`main` への push で `.github/workflows/pages.yml` が自動デプロイします。
初回のみリポジトリの **Settings → Pages → Build and deployment → Source** を
**GitHub Actions** に設定してください。

## 中身をいじる

ゲーム内容はすべて [`js/data.js`](js/data.js) に定義されています。
配列に1要素足すだけで、組合員・強化・実績・速報テロップを増やせます。

```js
// js/data.js
const GENERATORS = [
  { id:'rookie', icon:'🐣', name:'新入組合員', base:0.1, cost:15,
    desc:'…', quips:[ /* 強化6段階ぶんのフレーバー */ ] },
  …
];
```

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の骨格 |
| `css/style.css` | 見た目 |
| `js/data.js` | **ゲーム内容（ここを編集）** |
| `js/game.js` | 計算・セーブ・描画のエンジン |

## 注意

登場する団体・人物・出来事はすべてフィクションです。特定の組織や個人とは関係ありません。
